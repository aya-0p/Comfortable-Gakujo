# Comfortable-Gakujo
![version](https://img.shields.io/badge/version-1.12.0-green)

## 注意事項
- 非公式の拡張機能です。
- 生成AIによって生成されたソースコードが利用されています。
- 設定や非表示課題、成績通知の比較用データはブラウザのローカルストレージに保存します。以前のCookieデータは自動移行します。
- この拡張機能は機能11の実現のため、ローカルストレージの機能を使用します。なお、機能を利用しない限り、ローカルストレージは使用されません。
- 学情の画面構成などが変更されることで正常に動作しなくなるおそれがあります。
- 無責任、無保証です。利用によって、いかなる問題が発生しても責任を負いません。

## 機能
- 1~4, 10の機能は「課題・アンケートリスト」のページにて自動実行されます。
- 10の機能は「課題・アンケート詳細」のページにて自動実行されます。
- 5の機能は「課題・アンケートリスト」のページにて利用可能です。
- 6, 8の機能は「ホーム画面（学生・保護者）」のページにて自動実行されます。
- 11の機能は「ホーム画面（学生・保護者）」のページにて利用可能です。
- 14の機能は「ホーム画面（学生・保護者）」のページにて自動実行されます。
- 12の機能は「成績情報」のページにて自動実行されます。
- 15の機能は「授業参考情報一覧」のページにて自動実行されます。
- 7の機能はシングルサインオンの同意画面にて自動実行されます。
- 9, 13の機能は学情の全ページにて自動実行されます。
- 8の機能は「ホーム画面（学生・保護者）」のページにてON/OFFを切り替えることができます。
- 設定・非表示課題・成績通知のデータはローカルストレージに保存します。
- 11の機能はローカルストレージを使用しますが、この機能を利用しない限りローカルストレージは使用されません。

### <ins>1. 自動並び替え機能 [ver1.1.0-]</ins>

課題・アンケートを締め切り日時順に並べ、表示件数をallにします。表示中の項目が対象です。

### <ins>2. 締め切り日時 強調表示 [ver1.1.0-]</ins>

締め切り時刻が午前中（00:00〜11:59）の場合、赤太字で強調します。

### <ins>3. カウントダウン表示 [ver1.1.0-]</ins>

締め切りまでの残り時間を1秒ごとに表示します。

- 3日未満：オレンジの太字
- 1日未満：赤の太字・下線付き
- 締め切り後：「締切済み」

表示には±1秒程度の誤差が生じる場合があります。

### <ins>4. 提出済み課題 背景色変更 [ver1.2.0-]</ins>

提出済みの課題の行を黄緑色にします。

### <ins>5. 課題 非表示機能 [ver1.3.0-]</ins>

課題の左側の「−」で非表示にし、一覧下の「非表示にした課題・アンケート」の「＋」で戻せます。非表示状態はローカルストレージに保存します。以前のCookieのデータは自動で引き継ぎ、保存に成功したデータのCookieを削除します。

トップページの未提出課題リストには反映されません。

### <ins>6. 未提出課題の件数 補正機能 [ver1.3.0-]</ins>

トップページの未提出課題の件数を補正し、通常の課題を赤文字、非表示にした課題を灰文字で表示します。提出期間内の未提出課題が対象です。

### <ins>7. シングルサインオンの同意画面 自動同意機能 [ver1.4.0-]</ins>

シングルサインオンの確認画面で、デフォルトの送信属性のまま自動同意します。「過去のリクエスト」画面ではログインを再試行します。

### <ins>8. 成績更新通知機能 [ver1.5.0-]</ins>

トップページへのアクセス時と通知をONにした直後に成績明細を確認し、変更があれば通知します。画面の移動はありません。初期設定はOFFで、トップページ右上から切り替えられます。

初回保存と旧形式からの移行時は通知せず、同じ形式の前回データから変化した場合のみ通知します。通知のON/OFF設定・比較用ハッシュ・更新通知フラグはローカルストレージに保存します。以前のCookieデータは自動で引き継ぎ、保存に成功した後にCookieを削除します。確認失敗時は前回の情報を保持し、成績情報を開くと通知が消えます。成績画面の閲覧だけでは比較用データを更新しません。

### <ins>9. サイドバー [ver1.6.0-]</ins>

「シラバス」「授業情報」「課題提出」「履修登録」「成績」「単位情報」へのサイドバーを追加します。「単位情報」は中間画面を表示せずに開きます。画面幅が狭い場合は表示しません。

### <ins>10. 課題提出取り消し時 課題詳細への自動遷移機能 [ver1.7.0-]</ins>

課題の提出を取り消した後、元の課題詳細画面へ自動で戻ります。

### <ins>11. ホーム画面 ヘッダー画像カスタマイズ機能 [ver1.8.0-]</ins>

トップページ右上の「背景設定」から、表示範囲を「横長（ヘッダー）」「画面全体」から選択できます。通常（3日以上）・締切まで1日以上・3日未満・締切まで1日未満・課題なしの4種類の画像を個別に設定できます。

画像と表示範囲は設定画面内のプレビューや「ページでプレビュー」で確認し、「変更を保存」で反映します。「ページでプレビュー」は選択中の状態の背景を実際のトップページに一時表示します。「設定に戻る」で編集へ戻れます。「キャンセル」では変更を破棄します。「この状態の画像を解除」で選択中の画像だけを解除できます。画像は縦横比を保ってブラウザ内に保存し、表示時に中央を基準に表示範囲を埋めます。以前の保存画像は通常の画像として引き継ぎます。

画像未設定の場合、通常は標準画像、締切まで3日未満の場合は警告柄、課題なしは通常の画像を使用します。「課題なし」はトップページに締切前の未提出課題がない状態です。保存容量が不足する場合は、画像を小さくするか、ほかの状態の画像を解除してください。

### <ins>12. 成績情報 年度・学期フィルター機能 [ver1.9.0-]</ins>

成績を年度・学期で絞り込めます。初期表示では、8月〜翌年1月は直近の前期、2月〜7月は直近の後期を選択します。

### <ins>13. ファイルプレビュー機能 [ver1.10.0-]</ins>

添付のPDF・テキスト・画像（PNG・JPG・JPEG・GIF・WebP・BMP・AVIF）をページ内でプレビューできます。「ファイルをプレビュー」ボタンがある場合はクリックして表示します。

### <ins>14. トップページ 最短締め切りカウントダウン [ver1.11.0-]</ins>

トップページの未提出課題から、最も近い締め切りまでの残り時間を整数秒で表示します。締め切りを過ぎると次の課題へ切り替え、対象がなければ「締切前の課題はありません」と表示します。

- 3日未満：残り時間をオレンジの太字にし、ヘッダー背景を黄色と黒の警告柄に変更
- 1日未満：残り時間を赤の太字・下線付きにし、ヘッダー背景を鮮やかな赤と黒の、より強い警告柄に変更

背景は機能11で設定した表示範囲と各状態の画像に自動で切り替わります。締切まで3日未満の状態の画像が未設定の場合は上記の警告柄を表示します。

締め切りを読み取れない課題は対象外です。課題一覧で非表示にした課題も、トップページに表示されていれば対象になります。

### <ins>15. 授業参考情報 曜日・コマ別の科目選択 [ver1.11.0-]</ins>

授業参考情報の講義名を曜日別・コマ順に並べ、「月曜 1コマ」のように表示します。1・2時限を1コマ、3・4時限を2コマとして扱います。複数の授業枠がある科目は最初の曜日にまとめ、すべての枠を表示します。

履修時間割と年度・学期が一致する場合に適用します。照合できない科目は「曜日・時限未確認」にまとめ、時間割を確認できない場合は元の表示を保持します。
